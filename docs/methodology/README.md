# Methodology Overview

This directory contains documentation for the pattern-oriented LLM-assisted engineering methodology.

## Workflow Phases

The methodology follows these phases:

1. [Understand the task](workflow.md#31-understand-the-task) - Clarify requirements and constraints
2. Identify domain and authoritative sources
3. Perform gap analysis
4. Decompose gaps into tasks
5. Discover and select patterns
6. Establish missing patterns
7. Prepare execution tasks
8. Execute with appropriate models
9. Verify against acceptance criteria

See [workflow.md](workflow.md) for the complete workflow specification.
