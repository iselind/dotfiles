# Documentation Conventions

## Navigational vs Deep-Dive Documents

Documents are classified by their filename casing:

### Navigational Documents (UPPERCASE)
- Define structure, responsibilities, and navigation
- Keep under ~150 lines
- Examples: `README.md`, `CONVENTIONS.md`, `DESTINATION.md`

### Deep-Dive Documents (lowercase)
- Contain detailed explanations and procedures
- No length limits
- Examples: `workflow.md`, `patterns/add-api-endpoint.md`

## Proposed Document Types

The following uppercased navigational documents are allowed:

| Document | Purpose |
|----------|---------|
| `README.md` | Entry point, project overview |
| `CONVENTIONS.md` | Naming and file conventions |
| `DESTINATION.md` | Working vision document |
| `OPEN_QUESTIONS.md` | Uncaptured ideas and decisions |
| `ARCHITECTURE.md` | System architecture overview |

Additional navigational filenames may be introduced via `CONVENTIONS.md`.
