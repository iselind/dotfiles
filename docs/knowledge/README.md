# Knowledge

Domain knowledge documentation for relevant technologies, frameworks, and accumulated experience.

## Structure

Each technology or domain gets its own directory:

- `terraform/` - Terraform-specific knowledge
- `[other-tech]/` - Other technologies as needed

## Content Types

Knowledge documents capture:

- **References** - Links to authoritative documentation
- **Gotchas** - Unexpected behaviors or limitations  
- **Compatibility issues** - Version mismatches and workarounds
- **Practical tips** - Field-tested advice
- **Workarounds** - Solutions to known problems

See also our [principle](../../DESTINATION.md#link-to-what-others-know-preserve-what-weve-learned): *"Link to what others know; preserve what we've learned."*
