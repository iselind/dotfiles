# Claude Code Skills Reference

Reference material about [Claude Skills](https://claude.ai/docs/skills) (when available) and how to use them effectively.

## Skill Basics

- Skills are small, focused knowledge modules (~200 lines target)
- Each skill acts as an entry point for specific domain expertise
- Skills can load additional material as needed during execution
- Use skills for: workflow guidance, task delegation, pattern access

## When to Use Skills

- When a task requires specialized methodology knowledge  
- For orchestration of complex workflows
- As context managers to focus models on relevant information
- When delegating to specific domain expertise
