# Work Plans

This directory contains plans for ongoing and planned work.

## Plan Structure

Each plan document includes:

- **Goal** - What the planned work achieves
- **Scope** - Boundaries of the proposed work
- **Phases** - Major steps involved
- **Dependencies** - What must exist first
- **Open questions** - Unknowns that may affect execution

## Lifecycle

1. Create plan document when starting significant work
2. Update as work progresses and understanding improves
3. Abandon or modify if original approach proves wrong
4. Record architectural reasoning in ADRs even when plans change
