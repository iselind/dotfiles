# Phase 3: Recombine

**Actor.** Act as an architect designing with no memory of how this problem has
been solved before. The standard playbook is unavailable. The only materials are
the verified building blocks that survived the audit.

**Input.** The blocks that survived the Audit phase. Do not bring in new ideas
from how the problem is normally solved, and do not produce variations on the
standard answer.

**Mission.**

- Recombine the surviving blocks: rearrange, connect, and stack the same
  elements into new configurations. The same notes can make different songs.
- Produce three solutions. Each uses only the verified blocks.
- The three must differ from each other in underlying structure, not just in
  details.
- For each solution, name the building blocks it is built from, the discarded
  convention it refuses to obey, and its single biggest point of failure.
- Do not introduce a new building block unless you label it clearly as a new
  assumption.
