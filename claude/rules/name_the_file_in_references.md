When pointing at something in a file, such as a line, a section or a bullet, always name the file with its path. Never refer to "line 16" or "the 2b bullets" alone.

**Why:** User said, when a review message told them to "skim line 16 and the 2b bullets" without naming the file: "I'm not sure what you refer to saying ... as there's no file name reference." A line number or a section name means nothing without the file, and the conversation often has several files in play.

**How to apply:** In any message, give the path (repo-relative or absolute) next to the line number, section or heading, for example `docs/plans/CORE-955-terraform-k8s-migration-order.md`, Approach. Use the `file_path:line_number` form where there is a line.
